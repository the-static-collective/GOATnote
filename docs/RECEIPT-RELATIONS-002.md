# RECEIPT-RELATIONS-002 — relation birthdays after evidence

**Draft experiment, unmerged, no deployment.** Builds on GOATnote's Receipt Glass import PR #14 and native GOATedges / GOATrooms / TIME-CUT branch stack.

## Purpose

A person imports WebZ evidence as one frozen source, then notices a relationship to another frozen source days, months, or years later. The relationship has **its own birthday**. Neither source nor the underlying signed reLATTE evidence is retroactively changed.

## Manual workflow

1. Import one WebZ evidence packet using the existing separate, consent-based importer.
2. Open **Relate receipts**. Deliberately choose FROM (an imported receipt's original frozen source version) and TO (a different saved source version, including a human note or another imported receipt).
3. Type a relation, discovery trace, and evidence path. The editor shows the distinction between noticing and proving.
4. Select an existing GOATroom, or create a new **Receipt Witness Room**. Confirm once.
5. GOATnote atomically adds **one GOATedge** and Room references in one local notebook store. Edge is initially \`perceived\`, confidence \`low\`, never \`admitted\`. It has an append-only initial revision, local observation timestamp, and an immutable receipt-specific birth anchor.
6. Use native **TIME-CUT** to inspect the same Room before the edge's first-perceived time (no staircase), at the recorded birth (perceived staircase), or after later human edge revisions. TIME-CUT remains view-only and current Room membership is held constant.
7. Native GOATedges can subsequently change interpretation and stance with revision receipts. For receipt relations, the initial human-observed birthday and original endpoints are locked; re-pairing demands a *new* relation.

## Evidence and authority

- **reLATTE** owns native crossing and receipt verification.
- **WebZ Receipt Glass** inspects received evidence and exports source bytes + a strictly bounded ancestry report.
- **GOATnote** locally preserves source, human relation formation, date of recording, and future margins.
- A human relation can be \`perceived\`, \`proposed\`, \`admitted\`, \`weakened\`, \`refused\`, or \`unresolved\` **only as a GOATnote local navigation status**. It does not upgrade the upstream receipt, source identity, external world, or custody permission.
- \`firstPerceivedAt\` is generated by the device clock **at human confirmation**, not the time the original sources were authored or signed. It is not a trusted external clock.
- GOATrooms today stores the current occupant list; TIME-CUT varies the recorded edge state, **not** historic Room membership. An older cut may still display a currently placed source with a ghost edge.
- GOATnote stays unencrypted browser localStorage. Do not use this for sensitive testimony without separate protection and backup.

## Code and gates

- \`receipt-relations.mjs\` — pure source-pin and edge/Room transaction constructor; no mutation of input notebook.
- \`receipt-relations-ui.mjs\` — deliberately chosen source references, explicit human confirmation, single notebook write, no network.
- \`goatedges.js\` — fixes existing note title carry and locks birthday/endpoints for flagged receipt relations while allowing ordinary human stance revisions.
- \`tests/receipt-relations.test.mjs\` — adversarial consent/source/address checks and **real native GOATedges + GOATtimeAPI.snapshot** temporal replay under an isolated DOM facade.

Run \`node tests/receipt-relations.test.mjs\`, \`node tests/webz-receipt.test.mjs\`, \`node tests/cad-journal.test.mjs\`, \`node tests/smoke.mjs\` and \`node --check\` on modified modules. The new `tests/receipt_relations_browser.py` runs real headless Chromium at root and nested paths with a mobile viewport; it exercises explicit source selection, real confirmation, notebook reload, native GOATedges non-traversability, and native TIME-CUT before/after cuts. Physical-device, accessibility, and longer-term backup/restore review remain separate release gates.

**FIRST PERCEPTION != SOURCE BIRTH. CURRENT ROOM MEMBERSHIP != HISTORICAL ROOM MEMBERSHIP. EVIDENCE REF != ANCESTRY PROOF. GOATEDGE ADMISSION != reLATTE ADMISSION. REUNION != REVERSAL.**
