# PATH-ALL-HOME-001 — GOATnote → Workbench

On a note with a previously declared attention mark, choose Whole note or
select an anchored passage to make it the current target. Click
Copy selected attention handoff. A click explicitly builds one v0.1 JSON
envelope from the latest mark on the *currently selected target*, with
source-owned record and target IDs, original timestamp, prior source record,
note/version/offset locator, a bounded label, original dimensions and
explicit-none flag. The original source mark remains unchanged.

Paste the copied JSON into the Workbench Attention Shelf, preview the full
source metadata and byte digest, then separately choose Import reviewed copy.
Clipboard failure gives a selectable local textarea as fallback. This is
not automatic synchronization and does not export the note body, margins,
browser backup or other attention history. Exported content is a
self-reported source statement; Workbench cannot independently verify that
the source note still exists or that the JSON was not modified before import.
Passage labels include selected text (up to 160 characters); review sensitive
material before copying it elsewhere. GOATnote remains the owner of the
original declaration and exact version/offset anchors.
